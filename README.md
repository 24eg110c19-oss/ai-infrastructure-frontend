# 🚀 AI Infrastructure Learning & Evolution Platform

### Learn Infrastructure. Experiment with Technology. Understand AI.

A full-stack educational platform that helps students understand the evolution of computing infrastructure, from physical servers to cloud computing, containers, Kubernetes, and AI infrastructure.

## 🌟 Features

- 📊 Infrastructure monitoring for CPU, RAM, disk, and GPU usage
- 🖥️ Interactive infrastructure simulation
- 🤖 AI-assisted infrastructure analysis and recommendations
- 📚 Structured learning modules
- 🕒 Technology evolution timeline
- 🔔 Infrastructure alerts and statistics
- 👤 User registration and login
- 📈 Learning progress tracking

## 🛠️ Technology Stack

- React
- Vite
- JavaScript
- HTML and CSS
- Axios
- React Router
- Java Spring Boot REST API
- PostgreSQL

## ⚙️ Run Locally

### Prerequisites

- Node.js and npm
- Java and Maven
- PostgreSQL

### Install and start the frontend

```bash
git clone https://github.com/24eg110c19-oss/ai-infrastructure-frontend.git
cd ai-infrastructure-frontend
npm install
npm run dev
```

### Build for production

```bash
npm run build
```

## 🎯 Project Objective

The objective is to provide an affordable, student-friendly environment to learn infrastructure technologies through practical simulations, monitoring, and AI-assisted explanations.

**Learning approach:** Learn → Understand → Experiment → Use AI Assistance → Make Human Decisions → Understand the Next Technology.
